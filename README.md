# Homebrew tap for net-merge

[net-merge](https://github.com/rohit267/net-merge) uses all your network adapters at once: Wi-Fi, Ethernet,
USB tethering and phone hotspots.

```
brew install rohit267/tap/net-merge
```

This works on macOS (Apple Silicon and Intel) and on Linux (x86_64 and ARM). After installing, `brew info
net-merge` shows the one-time step that gives net-merge the rights it needs, and the
[net-merge README](https://github.com/rohit267/net-merge#readme) explains the rest.

The formula follows the latest net-merge release by itself (a workflow checks every few hours).
